        # Прогноз температуры стали в ковше

Виртуальный датчик температуры стали на установке внепечной обработки: модель оценивает температуру контрольного (последнего) замера партии по начальной температуре и выполненной обработке — нагревам электродами, добавкам сыпучих и проволочных материалов, продувке газом.

Выпускной проект программы Data Scientist Plus Яндекс Практикума, трек «Промышленность» (заказчик — металлургический комбинат «Стальная птица»).

**Built with PriorLabs-TabPFN.**

## Результат

| Модель | MAE на кросс-валидации, °C | MAE на test, °C |
|---|---|---|
| **TabPFN v2** (итоговая) | 5.64 | **5.63** (R² 0.51) |
| TabM | 5.93 | — |
| Ridge | 5.94 | — |
| Случайный лес | 6.11 | — |
| LightGBM + Optuna | 6.20 | — |
| CatBoost + Optuna | 6.30 | — |
| Константа (медиана) | 7.88 | 8.21 |

Требование заказчика — MAE на тестовой выборке менее 6.8 °C. Наибольший вклад в прогноз дают начальная температура и характеристики нагрева; бленды моделей не дали выигрыша из-за высокой корреляции ошибок. 90%-е интервалы прогноза TabPFN согласуются с номиналом (покрытие 91% на test), и их ширина указывает партии, которые стоит замерить вручную. Подробные выводы, ограничения и рекомендации — в разделе 10 ноутбука.

## Методика

- Выборка делится **по времени**: train — первые 75% партий (1 743 партии, 3 мая – 11 июля 2019), test — последние 25% (581 партия, 11 июля – 10 августа).
- Разведочный анализ, отбор признаков и выбор модели выполняются только на train; кросс-валидация — `TimeSeriesSplit(5)`; test используется один раз.
- 65 признаков во вложенных наборах; вклад каждой группы оценён на кросс-валидации.
- Гиперпараметры бустингов подбираются в Optuna во вложенной кросс-валидации.
- Дополнительно (раздел 11): пошаговая оценка температуры между промежуточными замерами (MAE 6.56 °C на test против 8.86 °C у оценки «без изменений»).

## Запуск

1. Клонировать репозиторий: `git clone https://github.com/agnatsh001/steel-temperature-soft-sensor.git`.
2. Создать окружение: `conda env create -f environment.yml`.
3. Скачать базу данных в `data/`: `https://code.s3.yandex.net/data-scientist/ds-plus-final.db`. Веса TabPFN v2 уже лежат в `models/`.
4. Запустить ноутбук целиком (Restart Kernel and Run All). Полный прогон занимает около 1 ч 45 мин на MacBook Pro (Apple M1 Pro, 16 ГБ, CPU); время зависит от оборудования и версий библиотек.
